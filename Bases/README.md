# Bases de Rust

Ces leçons regroupent la syntaxe nécessaire pour créer un petit programme Rust, stocker des valeurs, afficher un résultat, écrire des fonctions et répéter des instructions.

## Sommaire

1. [Cargo](01-Cargo.md) : créer et exécuter un projet Rust.
2. [Variables](02-Variables.md) : déclarer et modifier des valeurs.
3. [Printing](03-Printing.md) : afficher du texte et des valeurs.
4. [Constants](04-Constants.md) : déclarer une valeur qui ne change jamais.
5. [Functions](05-Functions.md) : regrouper des instructions et retourner un résultat.
6. [Loops](06-Loops.md) : répéter des instructions avec `loop`, `while` et `for`.
7. [Types](07-Types.md) : reconnaître les types de valeurs courants.
8. [Conditions](08-Conditions.md) : choisir les instructions à exécuter.
9. [Arrays](09-Arrays.md) : regrouper plusieurs valeurs dans un tableau.

Chaque fichier présente une seule notion avec de petits exemples. Les nouvelles notions de base peuvent être ajoutées ici sous la forme d'un nouveau fichier au nom précis.

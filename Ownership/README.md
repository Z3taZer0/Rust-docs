# Ownership

L'ownership est le système utilisé par Rust pour gérer la mémoire sans ramasse-miettes. Ces leçons expliquent progressivement la propriété, les emprunts et les références.

## Sommaire

1. [Ownership](01-Ownership.md) : comprendre qui possède une valeur.
2. [Move, Copy et Clone](02-Move-Copy-Clone.md) : savoir ce qui se passe lors d'une affectation.
3. [Borrowing](03-Borrowing.md) : utiliser une valeur sans en prendre la propriété.
4. [Mutable References](04-Mutable-References.md) : modifier une valeur empruntée.
5. [String et &str](05-String-and-Str.md) : distinguer un texte possédé d'un texte emprunté.
6. [Slices](06-Slices.md) : emprunter une partie d'une chaîne ou d'un tableau.

Il est préférable de suivre ces leçons dans l'ordre, car chaque fichier réutilise les notions du précédent.

Les exercices correspondants et leurs corrections sont regroupés dans [Exercices — Ownership](../Exercises/Ownership.md).

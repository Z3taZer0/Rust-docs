# Exercices

Ce dossier contient les exercices associés aux leçons. Chaque exercice combine plusieurs notions déjà étudiées et possède une correction complète dans le même fichier.

## Sommaire

- [Bases](Bases.md) : douze exercices cumulatifs sur la syntaxe fondamentale.
- [Ownership](Ownership.md) : six exercices sur la propriété, les déplacements et les emprunts.
- [Types structurés](Structured-Types.md) : six exercices et un projet de synthèse sur les types personnalisés et les collections.

## Méthode de travail

1. Lire l'énoncé sans ouvrir la correction.
2. Écrire la solution dans `src/main.rs`.
3. Exécuter `cargo fmt`, `cargo clippy` et `cargo run`.
4. Comparer le comportement obtenu au résultat attendu.
5. Consulter la correction uniquement après une tentative complète.

Une correction représente une solution possible. Une autre solution est valide si elle respecte les contraintes et produit le résultat demandé.

# Types structurés

Ces leçons expliquent comment créer ses propres types et stocker un nombre variable de valeurs. Ces notions sont utilisées directement dans les programmes et moteurs de jeu écrits en Rust.

## Sommaire

1. [Structs](01-Structs.md) : regrouper plusieurs données dans un type.
2. [Methods](02-Methods.md) : associer des fonctions à un type avec `impl`.
3. [Enums](03-Enums.md) : représenter une valeur parmi plusieurs possibilités.
4. [Option](04-Option.md) : représenter la présence ou l'absence d'une valeur.
5. [Result](05-Result.md) : représenter la réussite ou l'échec d'une opération.
6. [Vectors](06-Vectors.md) : stocker un nombre variable de valeurs.

Suivre les leçons dans l'ordre permet de réutiliser progressivement les notions déjà étudiées.

Après ces six leçons, réalise le [projet de synthèse — Personnage et partie](../Exercises/Structured-Types.md#structured-project). Sa correction se trouve avec l'énoncé.
